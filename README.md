# Wedding Invitation

This is a static website. There are no package installs or build steps.

## Deploy

Publish the contents of this folder with any static website host. Keep `index.html`, `styles.css`, `script.js`, `wedding-music.mp3`, and the image files together in the site root.

## Preview locally

From this folder, run:

```powershell
python -m http.server 5500
```

Then open `http://127.0.0.1:5500/`.

The Google Maps link requires an internet connection. The included wedding audio plays after the visitor opens the invitation.
